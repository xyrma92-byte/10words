# 10Words — Учи английский по 10 слов в день

PWA-приложение для ежедневного изучения английских слов (русский перевод, флеш-карты с озвучкой, тест, стрик).

Сейчас в словаре **1042 слова** (полный A1 + большая часть A2).

## Как выложить на GitHub Pages (бесплатно, работает везде)

1. Создай новый репозиторий на GitHub (например, `10words` или `wordday`).  
   Сделай его **Public**.

2. Загрузи **все файлы из этой папки** в корень репозитория:  
   `index.html`, `app.js`, `style.css`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`.

   Можно через сайт GitHub (Add file → Upload files) или через Git.

3. Включи GitHub Pages:
   - Зайди в **Settings** репозитория
   - Слева **Pages**
   - В разделе **Build and deployment** → **Source**: выбери `Deploy from a branch`
   - Branch: `main` (или `master`), Folder: `/ (root)`
   - Нажми **Save**

4. Через 1–2 минуты появится ссылка вида:  
   `https://твой-ник.github.io/название-репозитория/`

5. Открой эту ссылку на телефоне → меню браузера → **«Добавить на экран «Домой»»** / **Add to Home Screen**.  
   Приложение установится и будет работать офлайн в любой сети.

## Локальный запуск

```bash
python3 -m http.server 8080
```
Открой http://localhost:8080

## Установка как приложение

- **iPhone**: Safari → Поделиться → На экран «Домой»
- **Android**: Chrome → Установить приложение
- **Mac**: Chrome/Edge → иконка установки в адресной строке

Прогресс сохраняется в браузере (localStorage).
